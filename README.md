Interior Design Portfolio
A minimalist, elegant portfolio website showcasing interior design projects, built entirely with vanilla HTML, CSS, and JavaScript with no frameworks, libraries, or backend required. All projects designed and visualized in Room Planner.

Features
- Responsive layout with a mobile-friendly navigation menu
- Project grid displaying room type, year, and cover image for each project
- Detail modal for each project with an image gallery (previous/next navigation and dot indicators)
- Clean, editable structure — project data is stored in a single JavaScript object for easy updates
- Neutral, sophisticated color palette suited for architecture/interior design portfolios

Built With
- HTML5
- CSS3 (Flexbox, Grid, custom properties)
- Vanilla JavaScript (no libraries or frameworks)

Project Structure
- index.html # Page structure and content
- style.css # Styling and layout
- script.js # Interactivity (menu, modal, gallery)
- Images/ # Project images

About
All projects featured were designed and visualized using Room Planner.
